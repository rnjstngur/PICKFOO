PICKFOO 최종 통합 소스 (웹 + Django/PostgreSQL + Android + 시작화면)

먼저 프로젝트 루트의 00_최종_통합본_실행가이드.md 또는 PICKFOO_실제앱_실행가이드.pdf를 읽으세요.
웹: backend/.env 설정 → venv / pip install → migrate → Django runserver → http://127.0.0.1:8000/index.html
Android 에뮬레이터: Django runserver 0.0.0.0:8000 → 03_안드로이드_에뮬레이터_준비.bat → Android Studio android 폴더 열기 → Run.
APK 실행 가능 여부는 Android Studio 설치·Gradle 빌드·실제 서버 연결 환경에서 확인해야 합니다.
주의: 앱 출시용 서버/DB/HTTPS/사진 스토리지는 아직 별도 운영 설정이 필요하며, 코드는 실행 시 테스트·검증이 필요합니다.
기존 원본을 덮어쓰지 말고 새 폴더에 풀어 사용하세요.
