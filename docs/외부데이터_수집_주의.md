# 외부 정보 후보 수집

`data/조합_원천데이터_수집양식.csv`는 실제 데이터가 **하나도 입력되지 않은 빈 양식**입니다.

- 수집 대상의 이용조건 및 공개 API 허용 범위 확인이 먼저입니다.
- 각 행에 출처·원문 URL·날짜·제품/브랜드/재료·가격과 실제 확인 근거를 기록합니다.
- 같은 조합인지 판단하는 '중복판정키'는 예: 브랜드+정규화된 재료+옵션 순서로 팀이 합의해 정의합니다.
- 가격·원재료·알레르기 정보가 실제 확인되지 않은 항목은 '미확인/추정'으로 명시합니다.
- 외부 서비스 좋아요/조회수 기록을 임의로 넣지 않습니다.
