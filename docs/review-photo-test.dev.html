📷 리뷰 사진 업로드 테스트

브라우저 콘솔에 코드를 붙여넣지 않고, 사진 업로드 API를 테스트하는 페이지야.

음식 조합 ID가 아닌 리뷰 ID를 입력해 줘. DBeaver의 catalog_recipereview 테이블에서 확인할 수 있어.

JPG, PNG, WebP · 최대 3MB. 개인정보가 없는 테스트용 사진을 사용해 줘.

먼저 PICKFOO 메인 화면에서 로그인한 뒤 진행해 줘.
저장된 사진 열어보기

이 페이지는 http://127.0.0.1:8765/review-photo-test.html 주소로 열어야 해. 서버가 제공한 사진 URL은 개발 환경의 공개 미디어 주소이므로 민감한 사진을 업로드하지 마.
